# Contexto do projeto SaudeMais

## Objetivo
Site academico que conecta idosos e PCDs a voluntarios e transporte comunitario para chegar aos postos de saude.

## Stack observada
- HTML5 nas paginas existentes.
- CSS3 em `css/styles.css` e em blocos `<style>` nas paginas.
- JavaScript em blocos `<script>` inline e em `js/acessibilidade.js`.
- Recurso externo atualmente usado: widget VLibras.

## Paginas existentes
- `index.html` (Inicio)
- `sobre-nos.html` (Sobre o Projeto)
- `como-funciona.html`
- `preciso-de-ajuda.html`
- `quero-ajudar.html`
- `mapa.html`
- `unidades.html` (Postos de Saude)
- `configuracoes.html` (Acessibilidade)
- `seguranca.html`
- `contato.html` (Contato e Parcerias)

## Limites
- Idioma da interface: portugues do Brasil (`pt-BR`).
- Identidade visual observada: azul, branco e cinza.
- Nao incluir novas paginas, modulos ou dependencias sem confirmacao.
- Nao registrar nomes, dados pessoais, tokens ou identificadores privados neste plano.
